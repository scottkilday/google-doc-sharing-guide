# How to Suggest Edits in a Google Document (Comment Mode vs Editing Mode)

## Overview
This guide explains two user modes in a Google Document: commenting and editing.

## When to Use Each Mode
**Suggesting Mode** allows users to propose changes and add comments without modifying the text. **Editing Mode** allows users to directly change the document, replacing or deleting text.

## How to Switch to Suggesting Mode
1. Open the Google Document.
2. Click the **Editing** button in the top-right corner of the toolbar.
3. From the dropdown menu, select **Suggesting**.

## How to Suggest an Edit
1. Highlight the text you want to suggest edits to.
2. Type your suggested changes directly. The text you propose will appear in green, and the original text will be crossed out.
3. To add a comment, click the **Comment** button (speech bubble icon) in the toolbar.

## How to Switch Back to Editing Mode
1. Click the **Suggesting** button in the top right corner.
2. From the dropdown, select **Editing**.

## Result
Collaborators can view all suggested edits and comments in the shared document. Changes made in Editing mode will be applied directly, while changes in Suggesting mode can be accepted or rejected by collaborators.
