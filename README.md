# How to Create and Share a Google Document with Editing Permissions

## Overview
This guide explains how to create a Google Document and share it with editing permissions. It is intended for users who need to collaborate with others in real time.

## Prerequisites
- A Google account
- Internet access
- A web browser (e.g., Chrome, Safari)

## Steps

1. Go to **docs.google.com**.
2. Click **Blank** to create a new document.
3. Enter a title for your document.
4. Click the blue **Share** button in the top-right corner.
5. Enter the recipient's email address.
6. Click the dropdown next to the email field.
7. Select **Editor**.
8. Click **Send**.

## Result
The document is shared with the specified recipient. The recipient can edit the document and collaborate in real time.
